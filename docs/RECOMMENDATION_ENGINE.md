# LottoPilot 推荐与回测引擎规格

## 1. 基本事实

对同一彩种而言，每一组合法单注组合的理论中奖概率相同。LottoPilot 的“模型评分”表示组合在历史统计特征、结构分布、稳定性和多样性约束下的相对排序，不表示真实概率被改变。

## 2. 输入与输出

### 输入

- 彩种：`ssq` 或 `dlt`。
- 目标期号。
- 截止目标期之前的已校验开奖记录。
- 策略配置版本。
- 随机种子。
- 可选 AI 配置。

### 输出

- 固定 5 组合法组合。
- 每组统计分、AI 分、最终分、标签和解释。
- 数据截止期、快照哈希、策略版本和 seed。
- 候选池数量、筛选数量和运行耗时。

## 3. 可复现性

默认 seed：

```text
uint64(sha256(lottery_type + target_issue + strategy_profile_version)[0:8])
```

同一数据快照、策略配置、代码版本和 seed 必须产生相同的统计候选和排序。AI 输出具有外部不确定性，因此单独保存 AI 原始响应哈希、模型名和请求参数摘要。

## 4. 数据窗口

默认计算多个窗口并归一化融合：

- 最近 30 期。
- 最近 60 期。
- 最近 120 期。
- 全部历史。

默认时间衰减：

```text
weight(age) = exp(-lambda * age)
```

`age=0` 表示最近一期。lambda 按策略配置保存，禁止在代码中散落魔法数字。

## 5. 号码级特征

对每个球计算：

- 窗口出现频率。
- 时间衰减频率。
- 当前遗漏期数。
- 平均遗漏、最大遗漏和遗漏标准分。
- 最近出现间隔。
- 窗口趋势：短窗口频率减长窗口频率。
- 与上一期是否重复。
- 不同窗口排名稳定性。
- 共现统计只作为弱特征，必须平滑并限制权重。

所有特征都需要记录公式、窗口和归一化方式。

## 6. 组合级特征

### 通用

- 和值。
- 跨度：最大号减最小号。
- 奇偶比。
- 大小比；分界点由彩种配置定义。
- 分区分布。
- 连号数量和最大连续长度。
- 与最近一期的重复数量。
- 尾数分布。
- 号码间距的均值和方差。
- 历史结构分位数位置。

### 双色球默认分区

```text
1–11, 12–22, 23–33
```

### 大乐透前区默认分区

```text
1–12, 13–24, 25–35
```

分区边界属于策略配置，不写死在 UI。

## 7. 候选生成

默认生成 50,000 组候选，可在 10,000–200,000 范围调整。

候选来源按配置混合：

1. 均匀随机采样，保证基线覆盖。
2. 按号码级分数加权的无放回采样。
3. 结构目标采样，使和值、跨度和分区覆盖历史常见区间。
4. 少量探索采样，保留冷门结构。

生成后立即执行：

- 彩种规则校验。
- 内部去重。
- 排序规范化。
- 极端结构软惩罚，而不是简单删除所有极端组合。

## 8. 评分模型

首版采用可解释的线性/树模型组合，不把深度学习作为上线前提。

概念公式：

```text
statistical_score =
    number_score
  + structure_score
  + temporal_stability_score
  + calibrated_backtest_score
  - extreme_penalty
```

所有子分数先映射到 `[0,1]`，最终展示分映射到 `[0,100]`。权重来自 `strategy_profiles.config`。

### 结构评分

使用历史分布的平滑密度或分位数，不要求组合完全贴近均值。默认保留中间 80% 分布的主要权重，同时为尾部保留非零分数。

### 稳定性评分

比较 30/60/120 期窗口下的候选分数。高分但对窗口极端敏感的组合获得稳定性惩罚。

## 9. AI 二次排序

- 只把统计排名前 30–50 组传给 AI。
- AI 返回候选 ID、0–100 评分、标签和一句解释。
- AI 权重默认不超过最终分的 10%。
- AI 只能在候选池中排序，不新增号码。
- 返回缺项、重复 ID 或非法 JSON 时，本次 AI 排序标记 failed，统计排序继续生效。

```text
final_score = statistical_score * 0.90 + ai_score * 0.10
```

权重可设为 0；上限由后端校验。

## 10. 最终 5 组多样性选择

从最终排序列表依次选择，同时应用重合约束。

默认约束：

- 双色球任意两组红球重合不超过 3 个；蓝球优先分散。
- 大乐透任意两组前区重合不超过 3 个；后区完全相同的组合优先避免。
- 5 组整体应覆盖不同和值、奇偶和分区结构。

如果高分候选无法满足全部约束，按固定顺序逐级放宽，并在运行记录中保存放宽级别。

多样性选择使用最大边际相关性（MMR）：

```text
MMR(candidate) = relevance(candidate) - diversity_lambda * max_similarity(candidate, selected)
```

## 11. 下一期号

- 优先依据官方最新期号和官方日期规则推导。
- 期号推导结果标记为 `expected`，只有官方发布后才标记 `confirmed`。
- 推荐可以绑定 expected 目标期，开奖同步后自动关联正式 draw。

## 12. 推荐复盘

开奖写入后，对同彩种、同目标期的推荐自动计算：

- 主区命中数。
- 次区命中数。
- 奖级映射（按当前官方规则配置）。
- 5 组中的最佳命中。
- 推荐排名与命中表现。

奖级规则需要独立版本化，避免规则变化影响历史复盘。

## 13. 滚动回测

### Walk-forward 规则

对于目标期 `t`：

```text
training_data = draws where draw_date < target.draw_date
```

特征标准化、权重校准、窗口选择都只能使用 `training_data`。

### 随机基线

每个目标期使用相同 seed 派生若干组均匀随机 5 注，默认 100 次 baseline trials。比较推荐策略和随机策略的分布，而不是只比较一次随机结果。

### 指标

- 主区平均命中数。
- 次区平均命中数。
- 每期最佳一组命中数。
- 命中至少 N 个主区号码的期次占比。
- Top-1 与 Top-5 表现。
- 相对随机基线差值及置信区间。
- 运行时间和候选生成吞吐量。

### 防数据泄漏测试

- 修改目标期开奖值不得改变该目标期生成前的特征。
- 数据截断到同一 cutoff 时结果必须一致。
- scaler、分位数、权重和特征选择器都在每个训练窗口内拟合。

## 14. 模型升级门禁

新策略成为默认版本前必须：

1. 通过合法性和可复现性测试。
2. 在固定历史区间完成 walk-forward 回测。
3. 与当前默认策略、均匀随机基线比较。
4. 保存配置、代码 commit 和报告。
5. 人工确认后把 `is_default` 切换到新版本。

回测表现不足时仍可保存为实验策略，不覆盖当前默认配置。


## Auto hit optimization

On each generate click, LottoPilot automatically walk-forward evaluates a small strategy grid on recent history and uses the best historical hit/prize-proxy config for the current 5 tickets.

- Goal: maximize historical hit/prize proxy for the selected 5 tickets
- User action: only click generate
- This is not a claim of higher true winning odds
