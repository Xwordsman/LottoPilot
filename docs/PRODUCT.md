# LottoPilot 产品规格

## 1. 目标

为用户提供一个简单的 Web 工具：自动维护双色球和大乐透历史开奖数据，展示统计分析结果，生成每期 5 组候选组合，并用历史滚动回测衡量排序策略。

## 2. 目标用户

- 想快速查看历史开奖统计的个人用户。
- 想保存每期推荐并复盘策略的用户。
- 想更换 AI 服务商、调整模型和查看分析报告的管理员。

## 3. 不做的事情

- 不接入购买彩票、充值、支付或代投。
- 不承诺提高真实中奖概率。
- 不把大模型输出直接当作合法号码，所有号码必须经过后端规则校验。
- 首版不做多租户、复杂 RBAC、短信登录和移动原生 App。

## 4. 核心用户流程

### 4.1 首次启动

1. 用户打开站点。
2. Setup Wizard 检查数据库连接和初始化状态。
3. 创建管理员账号。
4. 选择是否配置 AI；未配置 AI 时仍可运行统计引擎。
5. 系统同步双色球和大乐透历史数据。
6. 进入首页。

### 4.2 查看本期推荐

1. 在顶部选择双色球或大乐透。
2. 首页展示最新开奖期号、下一期信息、数据更新时间和 AI 状态。
3. 点击“生成本期 5 组”。
4. 后端生成候选池、评分、去重和多样性筛选。
5. AI 对前 N 个候选做解释或受限二次排序。
6. 页面展示 5 组组合、模型评分、标签、解释和生成时间。
7. 用户可以保存、复制、导出或重新生成。

### 4.3 复盘

1. 打开“推荐记录”。
2. 选择某一期推荐。
3. 开奖数据更新后，系统自动计算命中结果。
4. 查看命中数量、排名、策略版本和回测上下文。

## 5. 页面清单

| 路由 | 页面 | 主要内容 |
|---|---|---|
| `/setup` | 初始化向导 | 管理员、数据库、AI、数据同步 |
| `/login` | 登录 | 管理员登录 |
| `/` | 推荐首页 | 彩种切换、5组候选、状态和快捷操作 |
| `/history` | 历史开奖 | 分页、期号、号码、来源、同步状态 |
| `/analysis` | 统计分析 | 频率、遗漏、和值、跨度、区间、奇偶、趋势 |
| `/backtests` | 历史回测 | 时间窗口、策略版本、随机基线、结果图表 |
| `/recommendations` | 推荐记录 | 推荐归档、命中复盘、导出 |
| `/data` | 数据管理 | 全量同步、增量同步、CSV/XLSX 导入、错误记录 |
| `/settings/ai` | AI 设置 | Base URL、Key、模型、测试连接、任务开关 |
| `/settings/system` | 系统设置 | 时区、同步时间、展示偏好、日志级别 |

## 6. 首页信息层级

首屏必须先解决“本期看什么”，按以下顺序排列：

1. 彩种切换和数据状态。
2. 下一期信息。
3. 5 组候选组合。
4. 每组评分、结构标签和 AI 解释。
5. 生成、保存、复制、导出操作。
6. 统计摘要和回测入口。

## 7. 推荐卡片字段

每组推荐至少展示：

- 排名：1–5。
- 前区/红球号码。
- 后区/蓝球号码。
- 模型评分：0–100 的相对分数。
- 结构标签：例如“和值中位”“奇偶 3:3”“三区均衡”。
- 与其他推荐的重合度。
- AI 解释状态：已生成、未配置、调用失败。
- 生成时间、算法版本、随机种子摘要。

## 8. 验收标准

- 新环境通过 Setup Wizard 后可以进入首页。
- 无 AI Key 时可以同步数据、查看统计和生成 5 组候选。
- 配置 OpenAI 兼容接口后可以测试连接并生成解释。
- 双色球组合严格满足 6 个红球和 1 个蓝球的范围与唯一性。
- 大乐透组合严格满足 5 个前区和 2 个后区的范围与唯一性。
- 同一数据快照、策略版本和 seed 可以复现相同推荐。
- 所有推荐都能在“推荐记录”中找到。
- 官方数据更新后只新增新期号，不产生重复记录。
